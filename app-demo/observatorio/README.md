# Investigadopedia Observatorio - prototipo mock

Prototipo local de un observatorio curador de apoyos IA para investigar.

## Que demuestra

- Catalogo curado por etapa de investigacion.
- Fichas con hecho observado, riesgo y resguardo.
- Chat auditor metodologico mock.
- Backend local sin dependencias externas.
- Exportacion de ficha Markdown.

## Ejecutar

```powershell
node server.js
```

Luego abrir:

```text
http://localhost:4177
```

## Limites

- No consulta modelos externos.
- No guarda datos.
- No reemplaza evaluacion experta.
- El dataset inicial es curado, no exhaustivo.
