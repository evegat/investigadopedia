# Herramientas IA para Sociología y Economía

## 🔬 Investigación Científica y Análisis de Literatura
- **[Future-House/paper-qa](https://github.com/Future-House/paper-qa)**: Biblioteca especializada en búsqueda y generación aumentada por recuperación (RAG) para literatura científica. Alcanza niveles "superhumanos" para leer PDFs, procesar papers completos, e identificar y extraer citas exactas para responder preguntas complejas de ciencia.
- **[assafelovic/gpt-researcher](https://github.com/assafelovic/gpt-researcher)**: Agente autónomo diseñado para la investigación en línea en general. Automatiza el rastreo web, consolida información de más de 20 fuentes y redacta informes detallados con referencias. Excelente para crear skills que realicen estados del arte o recopilación de datos macroeconómicos.

## 🏛️ Economía, Sociología y Políticas Públicas (Simulación Social)
- **[salesforce/ai-economist](https://github.com/salesforce/ai-economist)**: Framework diseñado para modelar dinámicas socioeconómicas usando agentes. Permite estudiar la interacción entre agentes (ciudadanos/empresas) y entidades gubernamentales, optimizando políticas económicas mediante aprendizaje por refuerzo.
- **[joonspk-research/generative_agents](https://github.com/joonspk-research/generative_agents)**: Repositorio oficial del famoso paper de la Universidad de Stanford sobre "agentes generativos". Simula comportamientos humanos creíbles (memoria, reflexión, planificación) y es fundamental para estudios sociológicos sobre cómo reaccionan las poblaciones ante diferentes estímulos.
- **[danielrosehill/Impact-Bond-Policy-Simulator](https://github.com/danielrosehill/Impact-Bond-Policy-Simulator)**: Herramienta de simulación multiagente que modela las perspectivas de distintas partes interesadas (gobierno, inversores, población) sobre propuestas de políticas públicas. Ayuda a identificar puntos de conflicto o apoyo político.
- **[FudanDISC/SocialAgent](https://github.com/FudanDISC/SocialAgent)**: Colección y entorno de simulación impulsado por LLMs centrado en dinámicas sociales. Abarca teoría de juegos, encuestas de opinión pública y simulaciones económicas.
- **[hanlulong/awesome-ai-for-economists](https://github.com/hanlulong/awesome-ai-for-economists)**: Lista curada (Awesome List) de librerías, Modelos Basados en Agentes (ABM) y frameworks de investigación automatizada, específicamente construida para economistas.

## 🛠️ Posibles Skills Ad-hoc para Antigravity
- **Skill `research-paper-qa`**: Una skill que se integre con los conceptos de paper-qa para analizar y sintetizar tu propia base de papers almacenados en un directorio.
- **Skill `policy-simulator`**: Una skill que permita definir un grupo de "personas" y lance un pequeño debate simulado para observar las reacciones ante una nueva ley.
